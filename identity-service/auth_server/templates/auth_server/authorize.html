Authorization Endpoint

This endpoint starts the demo authorization-code flow. In normal use the relying-party app sends the browser here with query parameters describing the client, redirect URI, requested scope, and PKCE challenge.

What it expects

  • client_id to identify the demo client
  • redirect_uri for the callback route
  • response_type=code for auth-code flow
  • scope such as profile.read
  • code_challenge and code_challenge_method for PKCE
