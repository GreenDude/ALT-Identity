Identity Provider

Protected UserInfo Endpoint

This endpoint returns the authenticated user's OpenID Connect claims as JSON when the request includes a valid Authorization: Bearer ... header. The bundled client uses the access token from the token exchange and renders the JSON on its profile page.

Request format

GET

Authorization: Bearer <access_token>
