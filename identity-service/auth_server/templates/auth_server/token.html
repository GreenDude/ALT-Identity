Identity Provider

Token Endpoint

This route accepts a POST and exchanges a valid authorization code for access, refresh, and ID tokens. The demo client calls it automatically from the callback step.

POST fields

  • grant_type=authorization_code
  • code from the authorize redirect
  • client_id matching the original request
  • redirect_uri matching the original request
  • code_verifier when PKCE is used

Endpoint URL

{{ endpoint_examples.token_url }}

Success response

{
  "access_token": "string",
  "refresh_token": "string",
  "id_token": "string",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "openid profile"
}
